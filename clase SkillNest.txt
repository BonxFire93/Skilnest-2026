Flask
Flask es un microframework web ligero y flexible escrito en Python, diseñado para crear aplicaciones web, APIs y microservicios de manera rápida y sencilla.
Se clasifica como "micro" porque proporciona herramientas básicas (enrutamiento, manejo de solicitudes) sin imponer componentes, permitiendo al desarrollador elegir sus propias librerías para bases de datos o validación.

microframework: Un microframework es un marco de desarrollo web minimalista y ligero, diseñado para manejar solicitudes HTTP y rutas con funcionalidad esencial, careciendo de componentes pesados como ORM o validación automática de datos.
Se enfoca en la simplicidad, flexibilidad y el rendimiento, siendo ideal para microservicios, APIs y prototipado rápido. (metodologia)

Una sesión es como una conversación persistente entre el cliente (por ejemplo, un navegador web) y el servidor.
Durante esta conversación, el servidor puede recordar información sobre el usuario, como su inicio de sesión o preferencias, para que la aplicación web pueda personalizar la experiencia del usuario en diferentes páginas o visitas al sitio.

¿Recuerdas al principio del curso, cuando creamos múltiples funciones en un solo archivo? La información y acciones de cada función era independiente, es decir que las funciones no tenían acceso a los datos de otras funciones a pesar de encontrarse en el mismo lugar.
Aquí sucede lo mismo, cada método que maneja una ruta es independiente del resto de las rutas.
Esto sucede dado a que el ciclo de solicitud y respuesta de HTTP no tiene estado.
¿Que significa esto? Que cada ciclo de solicitud/respuesta es independiente e ignora por completo la existencia e información del resto de las solicitudes.
Pero entonces, ¿cómo hacen los sitios web para recordar cuando alguien ya se registró, o la información de nuestro carrito de compras cuando estamos comprando? Esto se debe a que utilizan almacenamiento persistente de datos.
Una forma de persistencia muy usual es la sesión.
